## CAD

All parts which make up the construction are in the folder [parts](parts).

The following table contains all information about 3D printing the provided parts.
A 0.4mm nozzle was used, everything was printed from PLA on a Bambu A1 Mini.

| Name | Infill | Walls  |  Layer height | Plastic |
|:-:|:-:|:-:| :-:| :-:|
|  Bottom | 20 | 2 | 0.2 | 123g |
|  Middle | 20 | 2 | 0.2 |  63g |
|  Top    | 20 | 2 | 0.2 |  60g |
|  Wheel  | 40 | 2 | 0.2 |  20g |
|  Battery cover | 15 | 2 | 0.2 | 17g |

TIP: Hot glue the nut holes when you insert them so they don't fall out every time you have to disassemble it.
